# 永續小食堂 HTML 投影片

和美高中多元選修「永續小食堂」課程教材。

## 課次

- [2026-09-03 第一堂課](index.html)：課程簡介、升學制度插播、課程規則、分組活動，以及飲食與永續緒論。
- [2026-09-10 地球界限與食品工業化](lessons/2026-09-10/index.html)：食物版「誰是臥底」、食品工業化與資本主義下的食物供應，以及 draw.io 食物關係圖活動。

第二堂另附教師指南、30 張遊戲題目卡、學生任務頁、可編輯 draw.io 模板、PDF 與離線教材包。

## 使用方式

直接開啟 `index.html`，或在資料夾內執行：

```bash
python3 -m http.server 8000
```

再開啟 <http://localhost:8000>。

## 操作

- `←` / `→`、`PageUp` / `PageDown`：前後換頁
- `Space` / `Enter`：下一頁
- `Home` / `End`：第一頁／最後一頁
- `F`：全螢幕
- `N`：講者備註
- 觸控裝置可左右滑動換頁

## 設計與內容說明

- 字體使用 macOS 與常見系統內建繁中文字型，不依賴外部 CDN。
- 視覺以字級、字重與配色變化為主，抽象插畫只用於少數章節轉場。
- 升學制度補充以 115 學年度現行規則為基準；學生實際申請時，仍應查閱當年度簡章。
- 原稿中的教室口語與提問盡量保留，講者提示放在可按 `N` 開啟的備註面板。
